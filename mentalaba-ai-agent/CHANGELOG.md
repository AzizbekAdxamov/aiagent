# O'zgarishlar jurnali

Mentalaba AI Agent loyihasidagi barcha muhim o'zgarishlar ushbu faylda qayd etiladi.

## [Nashr qilinmagan]

### ✨ Dastlabki loyiha sozlamalari
- Loyiha tuzilishi va hujjat ramkasi
- Asosiy modul ta'riflari (universitetlar, yo'nalishlar, grantlar, yangiliklar)
- Prompt muhandisligi bilan AI agent arxitekturasi
- Frontend va backend hujjatlari
- API spetsifikatsiyalari va ma'lumotnomalar

### 🧠 AI Agent
- Tizim prompti va ishlab chiqaruvchi prompti ta'riflari
- Universitet qidiruvi, yo'nalish qidiruvi, grant qidiruvi, taqqoslash uchun vositalar tizimi
- Foydalanuvchi so'rovlarini tasniflash uchun intentsiyalarni marshrutlash
- Kontekstni boshqarish (xotira, sessiya, tarix, kesh)
- Shaxsiylashtirilgan takliflar uchun tavsiya mexanizmi
- Suhbat oqimi (salomlashish, kuzatish, aniqlashtirish, zaxira, yakunlash)

### 📚 Kontent modullari
- Universitet moduli CRUD, SEO va galereya qo'llab-quvvatlashi bilan
- Yo'nalish moduli ta'lim turlari, to'lovlar, transfer bilan
- Grant moduli filtrlash va foydalanuvchi tomoni ko'rinishlari bilan
- Yangiliklar moduli teglash va munosabatlar bilan

### 🎨 Frontend
- Suzuvchi harakat tugmasi bilan chat interfeysi
- Universitet/yo'nalish/grant karta komponentlari
- Taklif kartalari va yuklanish holatlari
- Yanpanel bilan mobil moslashuvchan tartib
- Tarix va xato holatlarini qayta ishlash

### ⚙️ Backend
- API xizmat qatlami arxitekturasi
- Vosita marshrutlagichi va intentsiya marshrutlagichi
- LLM xizmat integratsiyasi
- Kesh va qidiruv amalga oshirilishi
- Sessiyani boshqarish va loglash

### 🧪 Testlash
- API test spetsifikatsiyalari
- Prompt baholash ramkasi
- UI komponent testlari
- Chegara holatlari hujjatlari
- Benchmark ko'rsatkichlari

---

*Bu dastlabki loyiha sozlamalari. Rivojlanish davom etar ekan, batafsil o'zgarishlar qaydlari qo'shiladi.*
