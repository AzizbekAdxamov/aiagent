# Mentalaba AI Agent

> 🧠 **AI asosidagi ta'lim platformasi** — Talabalarga Efiopiya bo'ylab universitetlar, yo'nalishlar va grantlarni topishda yordam beradi.

---

## 📋 Umumiy ma'lumot

**Mentalaba AI Agent** — bu talabalarga Efiopiyadagi oliy ta'lim imkoniyatlarini o'rganishda yordam beradigan aqlli yordamchi. U shaxsiylashtirilgan tavsiyalar, universitetlar, akademik yo'nalishlar va grantlar haqida batafsil ma'lumot beradi.

Platforma kuchli AI agentni Efiopiya oliy ta'lim muassasalari haqidagi keng qamrovli ma'lumotlar bilan birlashtirib, intuitiv, suhbatlashish usulidagi tajriba taqdim etadi.

## 🧠 AI Agent arxitekturasi

AI agent quyidagilardan foydalanadi:
- **Intentsiyalarni tasniflash** — Foydalanuvchi so'rovlarini tegishli ishlovchilarga yo'naltirish
- **Vositalar tizimi** — Ma'lumot olish va harakatlar uchun modulli vositalar
- **Prompt muhandisligi** — Har bir stsenariy uchun puxta ishlab chiqilgan prompter
- **Kontekstni boshqarish** — Sessiya xotirasi va suhbat tarixi
- **Tavsiya mexanizmi** — Ma'lumotlarga asoslangan shaxsiylashtirilgan takliflar

## 🛠️ Texnologik stack

- **Frontend:** Responsiv dizayn bilan veb-ilova
- **Backend:** Vosita marshrutlash bilan API xizmatlari
- **AI/ML:** Intentsiyalarni tasniflash bilan LLM asosidagi agent
- **Ma'lumotlar bazasi:** Ta'lim ob'ektlari uchun relyatsion ma'lumotlar modeli
- **Kesh:** Samaradorlikni optimallashtirish qatlami
