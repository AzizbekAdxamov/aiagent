# Intentsiya: university_search

## Tavsif
Foydalanuvchi universitetlar haqida ma'lumot qidirmoqda.

## So'rov misollari

- "Addis Ababadagi universitetlarni toping"
- "Menga barcha davlat universitetlarini ko'rsat"
- "Addis Ababa universiteti haqida aytib bering"
- "Qaysi universitetlarda muhandislik dasturlari bor?"
- "Yotoqxonasi bor universitetlar"
- "Oromiya viloyatidagi universitetlar ro'yxati"

## Tasniflash kalit so'zlari

- university, universities, uni, college, institution
- Nom namunalari: "AAU", "Addis Ababa University"
- Joylashuv so'zlari: "in", "at", "near", "region"
- Harakat so'zlari: "find", "show", "list", "tell me", "search"

## Ishonch belgilari

- **Yuqori:** To'g'ridan-to'g'ri universitet nomi eslatilgan
- **O'rta:** Viloyat + universitetga oid kalit so'zlar
- **Past:** Umumiy ta'lim so'rovi

## Javob harakatlari

1. Qidiruv/filtr parametrlarini ajratib olish
2. `search_university` yoki `get_university` ni chaqirish
3. Natijalarni universitet kartalari sifatida formatlash
4. Kuzatuv takliflarini berish

## Kuzatuv takliflari

- "[Universitet nomi] tafsilotlarini ko'rish"
- "Ushbu universitetdagi yo'nalishlarni ko'rsat"
- "Bu yerda qanday grantlar mavjud?"
- "Boshqa universitet bilan taqqoslash"
