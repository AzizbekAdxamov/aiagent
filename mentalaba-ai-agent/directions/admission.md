# Yo'nalishlar — Qabul

## Umumiy ma'lumot

Har bir yo'nalish/dasturga oid qabul talablari. Bu universitet darajasidagi qabul ma'lumotlarini to'ldiradi.

## Ma'lumot maydonlari

| Maydon | Tavsif |
|-------|-------------|
| `min_entrance_score` | Minimal kirish imtihon bali |
| `subject_requirements` | Kerakli fanlar va minimal baholar |
| `capacity` | Mavjud o'rinlar soni |
| `selection_criteria` | Talabalarni tanlash usuli |
| `additional_requirements` | Qo'shimcha talablar (suhbat, portfel va boshqalar) |
| `notes` | Qo'shimcha qabul eslatmalari |

## Misol

```
Yo'nalish: Kompyuter fanlari (Bakalavr)
- Minimal kirish bali: 400/700
- Kerakli fanlar: Matematika (min 70%), Fizika (min 60%), Ingliz tili (min 60%)
- Sig'im: 200 talaba
- Tanlash: Bilimga asoslangan (eng yuqori ballar)
- Qo'shimcha: Dasturlash qobiliyat testi
```
