# Yangiliklar — SEO

## SEO metama'lumotlari

```html
<meta name="description" content="Yangilik maqolasi parchasi bu yerda..." />
<meta property="article:published_time" content="2026-03-15T10:00:00Z" />
<meta property="article:author" content="Mentalaba Team" />
<meta property="og:type" content="article" />
```
