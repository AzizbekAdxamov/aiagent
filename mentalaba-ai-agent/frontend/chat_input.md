## Holatlar

| Holat | Tavsif |
|-------|--------|
| Bo'sh | O'rin tutuvchi matn, yuborish o'chirilgan |
| Yozish | Yuborish tugmasi yoqilgan, limit yaqin bo'lsa hisoblagich |
| Yuborish | Yuklash ko'rsatkichi, kiritish o'chirilgan |
| Ovoz | Mikrofon ikonkasi pulslashadi (agar qo'llab-quvvatlansa) |
| Xato | Qizil chegara, xato xabari pastda |
