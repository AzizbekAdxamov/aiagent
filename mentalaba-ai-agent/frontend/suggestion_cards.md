# Frontend — Taklif kartalari

## Maqsad

Taklif kartalari foydalanuvchilarga nima so'rashlari mumkinligini kashf etishga yordam beradigan bosiladigan takliflarni taqdim etadi.

## Turlari

### Dastlabki takliflar (birinchi tashrifda ko'rsatiladi)
```
┌─────────────────────┐ ┌─────────────────────┐
│ 🏫                  │ │ 📚                  │
│ "Addis Ababadagi   │ │ "Akademik           │
│  universitetlarni   │ │  dasturlarni        │
│  toping"            │ │  o'rganing"         │
└─────────────────────┘ └─────────────────────┘
┌─────────────────────┐ ┌─────────────────────┐
│ 💰                  │ │ 📰                  │
│ "Stipendiyalarni    │ │ "Ta'lim             │
│  kashf eting"       │ │  yangiliklarini     │
│                     │ │  o'qing"            │
└─────────────────────┘ └─────────────────────┘
```

### Kontekstli takliflar (javobdan keyin)

Joriy kontekst asosida ko'rsatiladi:
- Uni ro'yxatidan keyin: "[Uni nomi] haqida batafsil aytib bering"
- Yo'nalishdan keyin: "Qabul talablari?"
- Grantdan keyin: "Qanday murojaat qilish kerak?"

### Kuzatuv takliflari

AI agent tomonidan suhbat oqimiga qarab yaratiladi:
- "Boshqa universitetlar bilan taqqoslash"
- "Viloyat bo'yicha filtrlash"
- "Menga ko'proq variantlarni ko'rsat"

## Interaksiya

- Bosish = foydalanuvchi xabari sifatida yuborish
- Kartalar paydo bo'lganda animatsiya qilinadi (bosqichma-bosqich)
- Mobilda gorizontal skroll
- Bir vaqtning o'zida maksimal 4 ta karta ko'rinadi
