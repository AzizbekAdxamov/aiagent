# Universitetlar — Qabul

## Umumiy ma'lumot

Har bir universitet uchun qabul ma'lumotlari, jumladan talablar, tartiblar, muddatlar va aloqa ma'lumotlari.

## Ma'lumot maydonlari

| Maydon | Tavsif |
|-------|-------------|
| `general_requirements` | Umumiy qabul talablari |
| `requirements_am` | Amhar tilidagi talablar versiyasi |
| `application_period` | Ariza topshirish davri (sanasi) |
| `application_fee` | Ariza topshirish to'lovi miqdori |
| `required_documents` | Kerakli hujjatlar ro'yxati |
| `selection_criteria` | Nomzodlarni tanlash usuli |
| `contact_info` | Qabul bo'limi aloqasi |
| `exam_requirements` | Kerakli kirish imtihon ballari |

## Qabul turlari

- **Bakalavriat** — Oddiy bakalavr dasturlari
- **Magistratura** — Magistr va PhD dasturlari
- **Transfer** — Boshqa muassasalardan ko'chirish
- **Xalqaro** — Xalqaro talabalar uchun
- **Uzluksiz ta'lim** — Kechki/dam olish dasturlari
