# PM2 Boshqaruv Qo'llanma (frontend + backend)

Mentalaba AI **2 ta alohida loyiha**, har birida o'z `ecosystem.config.js` bor:

| Loyiha | Papka | PM2 nomi | Port | Config fayli |
|---|---|---|---|---|
| Backend (aiagent) | `backend/` | `mentalaba-aiagent` | 3000 | `backend/ecosystem.config.js` |
| Frontend (ai_front) | `ai_front/` | `mentalaba-ai-front` | 3001 | `ai_front/ecosystem.config.js` |

> Ikkala loyiha **bitta serverda** birga ishlasa, loyiha ildizidagi birlashgan
> `ecosystem.config.js` dan foydalaning — bitta buyruq bilan ikkalasi ishga tushadi:
> `pm2 start ecosystem.config.js`

---

## 1. Boshlash

```bash
# Backend (backend papkasida)
cd backend
npm run build          # faqat 1-marta / kod o'zgarganda
pm2 start ecosystem.config.js

# Frontend (ai_front papkasida)
cd ai_front
npm run build
pm2 start ecosystem.config.js

# YOKI bitta serverda ikkalasi birga (loyiha ildizida):
cd ..
pm2 start ecosystem.config.js   # backend + frontend birgalikda
```

> `npm run build` kerak, chunki PM2 `next start` (production build) ni ishga tushiradi. Kodni har o'zgartirgandan keyin `build` + `pm2 restart <name>` qilish kerak.

## 2. Holatni ko'rish

```bash
pm2 list               # ikkala app holati
pm2 status
pm2 monit              # jonli dashboard (CPU, RAM, loglar)
pm2 logs mentalaba-aiagent   # faqat backend loglari
pm2 logs mentalaba-ai-front  # faqat frontend loglari
```

## 3. Restart / Stop

```bash
pm2 restart all                    # ikkalasini ham qayta ishga tushirish
pm2 restart mentalaba-aiagent      # faqat backend
pm2 stop mentalaba-ai-front        # faqat frontendni to'xtatish
pm2 delete all                     # PM2 ro'yxatidan butunlay o'chirish
```

## 4. Avtomatik ishga tushish (server qayta yuklanganda)

**Linux (VPS):**
```bash
pm2 save
pm2 startup            # so'ralgan buyruqni chiqarib, uni root bilan bajarish
```

**Windows:**
```bash
pm2 save
npm install -g pm2-windows-startup
pm2-startup install
```
(Windows'da `pm2 startup` o'zi ishlamaydi — `pm2-windows-startup` kerak)

## 5. Deploy (yangi kod chiqarganda)

```bash
# 1-repo: aiagent (backend)
cd backend && git pull && npm install && npm run build && pm2 restart mentalaba-aiagent

# 2-repo: ai_front (frontend)
cd ai_front && git pull && npm install && npm run build && pm2 restart mentalaba-ai-front
```

## 6. Muhim sozlamalar (ecosystem.config.js)

- `restart_delay: 3000` — yiqilganda 3 soniyadan keyin qayta ishga tushadi (crash-loop oldini oladi)
- `max_memory_restart: "1G"` — xotira 1 GB dan oshsa avtomatik restart
- `time: true` — loglarga vaqt tamg'asi qo'shadi
- Loglar: `./logs/pm2-out.log` (stdout) va `./logs/pm2-error.log` (stderr)

## 7. CORS / API URL (muhim)

- Frontend `.env` da `NEXT_PUBLIC_API_URL` backend manziliga qaratilgan:
  - Local: `http://localhost:3000`
  - Production: `https://api.mentalaba.uz` (yoki Vercel URL)
- Backend `.env` da `CORS_ALLOWED_ORIGINS` frontend domeni ko'rsatilgan:
  - Local: `http://localhost:3001`
  - Production: `https://ai.mentalaba.uz`

> **Eslatma:** `NEXT_PUBLIC_` o'zgaruvchilari **build paytida** joylanadi — o'zgartirsangiz `npm run build` qayta qilish shart!
